# Clipper for Obsidian

Clipper saves what you highlight on a web page into your Obsidian vault. Select text in your browser, click a bookmark, and the selection lands in the note you chose, converted to Markdown with a link back to the page.

## How it works

1. You create a **clipper** in Obsidian. A clipper says where clippings go: today's daily note, this week's weekly note, a specific note, or a canvas.
2. Each clipper has its own **bookmarklet**: a browser bookmark that runs a small script instead of opening a page.
3. On a web page, you select some text and click the bookmarklet. It converts the selection to Markdown in the browser and hands it to Obsidian.
4. Obsidian writes the clipping into the clipper's note.

You can have as many clippers as you like, for example one for your daily note and one per research topic.

:::info Clipper is an Obsidian plugin, not a browser extension
Install it from Obsidian's Community plugins. The browser side is a bookmarklet you drag to your bookmarks bar. Browsers that can't run bookmarklets can use a [generated Chrome-based extension](./clipping/bookmarklet.md#chrome-based-browsers-without-bookmarklets) instead.
:::
