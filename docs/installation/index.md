# Installation

Clipper is in Obsidian's community plugin browser.

1. Open **Settings → Community plugins** and turn off Restricted mode if it is on.
2. Click **Browse** and search for **Clipper**.
3. Click **Install**, then **Enable**.

The plugin's settings appear under **Settings → Clipper**.

You can also do a [manual installation](./manualinstallation.md).

## Requirements

- **Daily clippers** need the core **Daily notes** plugin, or the Periodic Notes plugin with daily notes turned on.
- **Weekly clippers** need the Periodic Notes plugin with weekly notes turned on, or the Calendar plugin.
- **Canvas clippers** need the core **Canvas** plugin.

Topic clippers have no requirements.
