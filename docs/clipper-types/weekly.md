# Weekly clippers

A weekly clipper writes to this week's weekly note.

- Weekly notes come from the **Periodic Notes** plugin with weekly notes turned on. The **Calendar** plugin's weekly note settings also work.
- Clipper uses that plugin's folder and format to find the note. If this week's note doesn't exist yet, Clipper creates it from your weekly template.
- If neither plugin is set up for weekly notes, Clipper shows a notice and writes nothing.

![The Base tab of a weekly clipper](/img/manual/editor-weekly-base.png)

The settings are the same as for a daily clipper. See [Base settings](../settings/base.md).
