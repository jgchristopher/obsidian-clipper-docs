# Getting started

This walks through one clipper from start to finish: a **topic** clipper that collects highlights about Rust into a note named `Rust`.

## 1. Add a clipper

Open **Settings → Clipper**. The table lists your clippers. A new install has one daily clipper named **Default Clipper**.

![The Clipper settings tab listing five clippers](/img/manual/settings-tab.png)

Click **+**. Give the clipper a name, pick a type, and click **Add Clipper**.

![The Add New Clipper form with the name Rust Reading and type topic](/img/manual/add-clipper.png)

The four types are explained in [Clipper types](./clipper-types/index.md).

## 2. Choose where clippings go

Click the gear icon next to the new clipper to open **Edit Clipper Settings**.

For a topic clipper, pick the note in **Topic Note**. Start typing and **click the note in the list**: typed text that isn't picked from the list is not saved.

Set **Header** to the heading clippings should go under, for example `Clips`, and **Header Level** to that heading's level. If the note doesn't have that heading yet, Clipper adds it.

![The Base tab of a topic clipper](/img/manual/editor-topic-base.png)

Every change saves as you make it. There is no Save button.

## 3. Install the bookmarklet

Open the **Browser** tab. Drag the link with your clipper's name to your browser's bookmarks bar.

![The Browser tab, with the bookmarklet link named Rust Reading](/img/manual/editor-browser.png)

Each clipper has its own bookmarklet. If you add a second clipper, drag its link too.

## 4. Clip something

On any web page, select the text you want and click the bookmarklet.

![A web page with two paragraphs and a list selected](/img/manual/select-text.png)

Your browser may ask whether to open Obsidian. Allow it.

## 5. Find the clipping

The selection is now in your note, under the heading you chose, as a task-list item linking back to the page, followed by the text you selected.

![The Rust note with the new clipping under Clips](/img/manual/result-topic.png)

Next, look at the [settings for each tab](./settings/base.md), or change how entries look with an [entry template](./settings/templates.md).
