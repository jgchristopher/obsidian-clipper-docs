What Is Ownership?

Every programming language has to decide how a program uses the computer's memory while it runs. Some use garbage collection, and in others the programmer allocates and frees memory by hand.

Ownership is a set of rules that govern how a Rust program manages memory.

Ownership Rules

  • Each value in Rust has an owner.
  • There can only be one owner at a time.
  • When the owner goes out of scope, the value will be dropped.

Keep these rules in mind as we work through the examples that illustrate them.
